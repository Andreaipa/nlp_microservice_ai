## Qué hace

```
imagen → detección de regiones → recorte → realce → OCR
       → normalización → resolución contra el inventario → JSON
```

El servicio responde a una sola pregunta: **¿qué información puedo
identificar en esta imagen?**. No decide nada de negocio. El backend
principal es quien determina qué movimiento registrar.

<Aside type="caution" title="Es un asistente, no un lector autónomo">
  La calibración empírica de umbrales concluyó que **no existe un punto de
  corte** que permita aceptar lecturas automáticamente con menos del 1% de
  error. El servicio siempre pide confirmación humana. Está medido y documentado
  en [Umbrales de confianza](/sistema/umbrales/).
</Aside>

## Una nota sobre honestidad de las cifras

Todas las métricas de esta documentación provienen de ejecutar los scripts de
evaluación sobre un conjunto de **test separado por identidad de cilindro**:
15 cilindros que el modelo nunca vio durante el entrenamiento. Ningún número
está estimado.

Los informes se regeneran con `make evaluate` y `make calibrate`, y quedan en
`models/` para poder contrastarlos.
